# Μεταγλωττιστής της Γλώσσας Dana (2025)

Αυτός είναι ένας πλήρης μεταγλωττιστής (compiler) για τη γλώσσα **Dana**, υλοποιημένος σε C++ με τη χρήση των εργαλείων **Flex**, **Bison** και **LLVM 18**. Ο μεταγλωττιστής παράγει ενδιάμεσο κώδικα LLVM IR, κώδικα Assembly x86_64 και τελικά εκτελέσιμα αρχεία.

## 📋 Προαπαιτούμενα

Για την εγκατάσταση σε συστήματα βασισμένα στο Debian (π.χ. Ubuntu), θα χρειαστείτε τα εξής:

* [cite_start]**Εργαλεία Ανάπτυξης**: `make`, `g++` [cite: 683, 684]
* [cite_start]**Γεννήτριες Αναλυτών**: `flex`, `bison` [cite: 138, 688, 690]
* [cite_start]**LLVM 18**: `llvm-18`, `clang-18` (για το linking και την παραγωγή τελικού κώδικα) [cite: 117, 119]

Εγκατάσταση προαπαιτούμενων:
```bash
sudo apt-get update
sudo apt-get install flex bison make clang-18 llvm-18
